# Dossier de documentation — Facturation PME

Ce dossier regroupe la documentation technique du projet de facturation PME. Il est conçu pour être lu par le jury et par l’équipe pédagogique.

## Contenu principal

- `Documentation_Complete.md` : documentation complète du projet regroupant tous les aspects techniques (contexte, architecture, stack, sécurité, déploiement AWS, CI/CD, monitoring, présentation orale)
- `architecture_diagram.svg` : schéma visuel de l'architecture de l'application

## Comment utiliser ces documents

1. Lire la documentation complète pour comprendre l'ensemble du projet
2. Consulter le schéma d'architecture pour visualiser les composants et les flux
3. Voir le README.md à la racine du projet pour les instructions d'utilisation

Ces documents sont structurés pour présenter le projet de manière professionnelle, sans référence directe aux demandes de rendu ou aux numéros de session.
